# 11 — วิทยานิพนธ์: AI ให้โครงสร้างต้นทุนที่ทำให้ advice-first เป็นจริงได้

> เอกสารแม่ของทิศทางใหม่ · ทดแทน `01-world-model.md` ในฐานะ "ทำไมถึงทำสิ่งนี้"

---

## 1. แก่นเดียวที่ต้องจำ

> **จุดยืน "advice-first" ที่ประกาศไว้ ไม่เคยเป็นไปได้เชิงต้นทุน — จนถึงตอนนี้**

`social-media-content-system` และ `tin-wealth-writer` เขียนจุดยืนไว้แล้วว่า: *คำแนะนำมาก่อนผลิตภัณฑ์ + โปร่งใสเรื่องค่าตอบแทน*

คำถามคือทำไมทั้งอุตสาหกรรมไม่ทำแบบนั้น **คำตอบไม่ใช่เรื่องศีลธรรม แต่เป็นเรื่องเลข**:

```
วางแผนครัวเรือนให้ครบจริง = 3-6 ชม./ราย
  (ความคุ้มครอง · เกษียณ · ภาษี · หนี้ · สภาพคล่อง · สวัสดิการรัฐ/นายจ้าง)

ที่ความมั่งคั่ง 1-30 ล้านบาท → เก็บค่าที่ปรึกษาให้คุ้ม 3-6 ชม. ไม่ได้
  → ทางเดียวที่ได้เงินคือขายผลิตภัณฑ์
  → คำแนะนำเอนเอียงตั้งแต่ต้น โดยไม่ต้องมีใครตั้งใจ
```

**AI ไม่ได้ให้กลยุทธ์ใหม่ มันตัดตัวเลข 3-6 ชม. ลง** ถ้าเหลือ 1 ชม. เศรษฐศาสตร์กลับด้าน: ให้คำแนะนำครบวงจรฟรีได้ แล้วหารายได้จากการลงมือแทน

## 2. ทำไมผู้เล่นเดิมแก้ตามไม่ได้

| ผู้เล่นเดิม | ทำไมติดกับ |
|---|---|
| **ตัวแทนประกัน** (หลักแสนคน) | รายได้ทั้งหมดคือคอมมิชชั่น · ไม่มีเครื่องมือ · turnover สูง · องค์กรแม่ไม่มีแรงจูงใจให้เปลี่ยน |
| **RM ธนาคาร / bancassurance** | มีโควตาผลิตภัณฑ์รายไตรมาส · คำแนะนำถูกกำหนดจากบนลงล่าง |
| **นักวางแผน CFP** | ทำได้ดีแต่จำนวนน้อยและแพง — ไปเสิร์ฟ HNW หมด |
| **แอปการลงทุน** (robo/แพลตฟอร์มกองทุน) | แตะเฉพาะ*การลงทุน* ไม่แตะความคุ้มครอง ภาษี หนี้ — ไม่ครบวงจร |

**ช่องว่างที่เหลืออยู่**: ไม่มีใครทำ **การวางแผนการเงินครัวเรือนแบบครบวงจร ที่ราคาระดับ mass-affluent** เพราะแรงงานที่ปรึกษาแพงเกินไป — **ข้อจำกัดนั้นคือสิ่งที่ AI ปลดออก**

การรื้อโครงสร้างค่าตอบแทนขององค์กรที่มีตัวแทนหลักแสนคนเป็นไปไม่ได้ในทางปฏิบัติ → **คนที่แก้ได้คือคนตัวเล็กที่ไม่มีอะไรจะเสีย**

## 3. ทำไมต้องเป็น Tin

ต้องมีครบสามอย่างพร้อมกัน ซึ่งในไทยน่าจะมีคนไม่กี่คน:

| ทุน | ทำไมจำเป็น |
|---|---|
| **ใบอนุญาต** | คู่แข่งที่เป็นบริษัทเทคไม่มี · เป็นทั้งกำแพงและคูเมือง · เป็นส่วนที่ AI แทนไม่ได้ตามกฎหมาย |
| **เขียนโค้ดเอง** | ตัวแทนคนอื่นไม่มี · ต้นทุนต่อการทดลองเกือบศูนย์ |
| **มีลูกค้าอยู่แล้ว** | สนามทดสอบและวงจรป้อนกลับที่มีอยู่จริง ไม่ต้องสร้างใหม่ |
| เขียนคอนเทนต์ไทยเป็น | ช่องทางจัดจำหน่ายที่ไม่ต้องซื้อ |
| Runway > 18 เดือน | ของหายากที่สุดสำหรับคนทำคนเดียว |

## 4. โซ่คอขวด — ใช้ของเดิมได้ทั้งเส้น

`01-world-model.md` เขียนโซ่ไว้ว่า `ต่อระบบได้ → เห็นว่ามันทำอะไร → พิสูจน์ว่าถูก → จำกัดความเสียหาย → รับผิดได้ → ปล่อยให้ทำเอง`

ในบริบทที่ปรึกษาการเงินไทย โซ่นี้แปลตรงตัว:

| ข้อต่อ | ในงานจริง |
|---|---|
| ต่อระบบได้ | ดึงข้อมูลลูกค้าเข้ามาได้โดยไม่ต้องคีย์มือ (สลิป · กรมธรรม์เดิม · พอร์ตกองทุน · หนี้) |
| เห็นว่ามันทำอะไร | ทุกข้อสรุปย้อนกลับไปหาตัวเลขตั้งต้นได้ |
| **พิสูจน์ว่าถูก** | **ทุกเลขคำนวณซ้ำได้และมีที่มา — hard gate เดียวกับที่ skill เดิมบังคับไว้แล้ว** |
| จำกัดความเสียหาย | AI ห้ามชี้นำรายผลิตภัณฑ์ · ขอบเขตชัดว่าอะไรต้องให้คนตัดสิน |
| **รับผิดได้** | **ผู้ถือใบอนุญาตเซ็น — จุดที่ AI แทนไม่ได้ และเป็นคูเมือง** |
| ปล่อยให้ทำเอง | ค่อยเป็นค่อยไป ตามที่กฎเกณฑ์อนุญาต (ดู `13`) |

## 5. Pricing — ใช้ taxonomy จากงานรอบเดิม

จาก `probe1-target-list.md`: **(ก) จ่ายเมื่อสำเร็จ** vs **(ข) จ่ายต่อชิ้นงาน**

ที่ความมั่งคั่ง 1-30 ล้าน **fee-based ล้วนไม่เวิร์ก** — เก็บค่าวางแผนปีละหลักหมื่นจากคนมีสินทรัพย์ 3 ล้านไม่ได้ คอมมิชชั่นจึงไม่ใช่โมเดลที่แย่ **มันเป็นโมเดลเดียวที่เป็นไปได้ในเซกเมนต์นี้**

→ **ปัญหาไม่ใช่โมเดลรายได้ ปัญหาคือเซกเมนต์และปริมาณ**
→ ทางออกมีสองทาง: **ขึ้นไปเซกเมนต์ที่ค่าตอบแทนต่อรายสูงพอจะเก็บ fee** หรือ **อยู่เซกเมนต์เดิมแต่รับลูกค้าได้ 5-10 เท่า** — Phase 0 คือสิ่งที่บอกว่าทางไหนเปิดอยู่

## 6. สิ่งที่จะทำให้วิทยานิพนธ์นี้ผิด

| สมมติฐาน | ถ้าผิดจะเป็นยังไง | ตรวจที่ |
|---|---|---|
| งานที่ปรึกษาส่วนใหญ่เป็น "การวิเคราะห์" ที่ AI ทำแทนได้ | ถ้าจริง ๆ เป็นงานความสัมพันธ์ 70%+ → AI ปลดล็อกน้อยมาก practice ตันเร็ว | **Phase 0** |
| ผู้ถือใบอนุญาตรายบุคคลส่งมอบคำแนะนำผ่านซอฟต์แวร์ได้ | ถ้าติดกฎ → รื้อแผนทั้งหมด | **`13` สัปดาห์แรก** |
| ลูกค้า 1-30 ล้านอยากได้ความลึก | ถ้าเขาแค่อยากรู้ว่าซื้อตัวไหนดี → advice-first ผิดสำหรับเซกเมนต์นี้ ต้องขึ้นบนหรือลงล่าง | Phase 1 |
| ตัวแทนคนอื่นจะจ่ายเพื่อเครื่องมือ | ARPU ต่ำ · รับเทคโนโลยีช้า · กระจัดกระจาย | Phase 2 probe |
| ใบอนุญาตเป็นคูเมือง | ถ้ากฎเปลี่ยนให้แพลตฟอร์มให้คำแนะนำได้โดยไม่ต้องมีคนเซ็น → คูเมืองหาย | เฝ้าดูต่อเนื่อง |
