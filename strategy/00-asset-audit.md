# 00 — Asset Audit: ทุนที่มีจริง และที่ไม่มี

> ⚠️ **ไฟล์นี้ต้องเติมเอง** — ส่วนที่ยืนยันแล้วกรอกไว้ให้ ส่วนที่เป็น `[กรอก]` ต้องตอบด้วยตัวเลขจริง ไม่ใช่ความรู้สึก
> เหตุผลที่ต้องมีไฟล์นี้: กลยุทธ์ที่ดีคือกลยุทธ์ที่**เข้ากับทุนที่มีจริง** ไม่ใช่ที่ดูดีบนกระดาษ

---

## ✅ ยืนยันแล้ว

| ทุน | รายละเอียด | ผลต่อกลยุทธ์ |
|---|---|---|
| **เงินทุน** | มีพอลงทุนและรอ payback ได้ | เลือกสนามที่ลึกได้ ไม่ต้องรีบหาเงินเดือนหน้า → **ไม่ควรรีบระดมทุน** |
| **เวลา** | เต็มตัว | ทดลองขนานได้ 3 probe พร้อมกัน |
| **ทักษะ build** | สร้างซอฟต์แวร์/agent ได้เอง | **ต้นทุนต่อการทดลอง ≈ 0** → กลยุทธ์คือ *ทดลองเยอะ* ไม่ใช่ *คิดนาน* — นี่คือ asset ที่แพงที่สุด |
| **ฐานต้นทุนไทย** | ค่าครองชีพต่ำกว่าคู่แข่งเป้าหมาย | runway ยาวกว่า 3–5 เท่าที่รายได้เท่ากัน → **อยู่ในเกมได้นานกว่า** |

---

## 📝 ต้องกรอก

**เงินและเวลา**
- Runway เป็นเดือนที่ไม่มีรายได้เลย: `[กรอก]` เดือน
- เพดานที่ยอมเสียได้โดยไม่กระทบชีวิต: `[กรอก]`
- ชั่วโมงทำงานลึกจริงต่อสัปดาห์ (ไม่ใช่ชั่วโมงที่ว่าง): `[กรอก]` ชม.
- **ความอดทน**: ถ้า 12 เดือนยังไม่มีรายได้มีนัย จะยังทำต่อไหม `[กรอก ตอบตรง ๆ]`

**เครือข่าย** (ตัวชี้ขาดของ probe — ถ้าเข้าถึงลูกค้าไม่ได้ ไอเดียดีแค่ไหนก็พิสูจน์ไม่ได้)
- รู้จักคนที่รัน AI agent ใน production กี่คน: `[กรอก]`
- รู้จักคนต่างชาติที่แนะนำต่อให้ได้กี่คน: `[กรอก]`
- ชุมชนออนไลน์ที่เราพูดแล้วมีคนฟังจริง: `[กรอก]`

**ความน่าเชื่อถือ**
- มีอะไรที่ทำให้คนแปลกหน้าเชื่อว่าเรารู้เรื่องนี้: `[กรอก]`
- ถ้าไม่มี → ต้องสร้าง (นี่คือเหตุผลหนึ่งที่ QW-4 free wedge tool มีค่า)

## ❌ สิ่งที่ไม่มี และแลกด้วยเงินไม่ได้

เขียนไว้ตรง ๆ เพื่อตัดสนามที่เข้าไปแล้วแพ้แน่ ๆ:

| ไม่มี | ตัดสนามไหนออก |
|---|---|
| ทีมขาย enterprise + ตราสัญลักษณ์ที่ CIO เชื่อ | สนามที่ต้องขาย C-level ตั้งแต่วันแรก (C8 compliance pack) |
| การอยู่ในโซนเวลาเดียวกับลูกค้า US/EU | สนามที่ต้องตอบเร็วแบบเรียลไทม์ / support 24-7 |
| ทีมปฏิบัติการจำนวนมาก | สนาม ops หนัก (B6 human review marketplace) |
| ความน่าเชื่อถือด้านกฎหมาย/ผู้สอบบัญชี | สนามที่ต้องเซ็นรับรองทางกฎหมาย (บางส่วนของ C7) |
| เงินทุนระดับที่แข่ง compute ได้ | ทุกอย่างที่ชั้น model/infra ระดับล่าง |

> **ข้อสังเกต**: ข้อจำกัดพวกนี้ไม่ได้ตัด F1/F2/F3 ออก — F1 ขาย**หัวหน้าฝ่ายผลิตภัณฑ์/ฝ่ายการเงินของบริษัทที่ขาย agent** ไม่ใช่ CIO ขององค์กรใหญ่ · F2 ขาย**นักพัฒนา** · F3 ขาย**ฝ่ายปฏิบัติการที่มี P&L** ทั้งสามกลุ่มปิดดีลแบบ async ได้

## คำถามที่ตอบยากแต่ต้องตอบ

1. เราอยากทำอะไรจนทำได้ 5 ปีแม้ตอนมันน่าเบื่อ: `[กรอก]`
2. ถ้าตัดเรื่องเงินออก อยากให้คนจำเราว่าเราสร้างอะไร: `[กรอก]`
3. จุดอ่อนของเราที่จะทำให้แผนนี้พังคืออะไร (ไม่ใช่ตลาด — เรา): `[กรอก]`

> ข้อ 3 สำคัญที่สุด เพราะแผนส่วนใหญ่ไม่ได้ตายเพราะตลาด แต่ตายเพราะคนทำเบื่อ ท้อ หรือไขว้เขวก่อนถึงจุดที่มันเริ่มได้ผล
