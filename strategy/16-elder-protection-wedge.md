# 16 — Wedge: ปกป้องพ่อแม่จากการฉ้อโกงยุค AI

> ตัดสินใจ 2026-09-16 · ฐานคิดอยู่ที่ [`17-advisor-relevance.md`](17-advisor-relevance.md)
> **สถานะ: ยังไม่ทดสอบกับใครเลย · ยังไม่มีสถิติไทย · ห้ามเขียนคอนเทนต์จริงจนกว่าจะผ่านสัปดาห์ที่ 1**

---

## 1. ปัญหาที่ wedge นี้แก้

แผนหลัก (`10`–`15`) มี practice แต่ขาดสองอย่าง:
- **ประตูเข้า** ที่ลูกค้าเจ็บจริงพอจะซื้อทันที
- **สะพานไปคนรุ่นพ่อแม่** ซึ่งถือความมั่งคั่งจริง โดยไม่ต้องขายอะไร

Wedge นี้แก้ทั้งสองพร้อมกัน

---

## 2. ทำไมมันเร่งด่วน

| หลักฐาน | ที่มา |
|---|---|
| ความเสียหายจากการฉ้อโกงออนไลน์ คนอายุ 60+ | **สหรัฐฯ: $3.1 พันล้าน (2022) → $7.748 พันล้าน (2025)** — ราว 2.5 เท่าใน 3 ปี |
| การฉ้อโกงที่ใช้ AI | **สหรัฐฯ: *คาดการณ์* แตะ $40 พันล้านปีหน้า** |
| การฉ้อโกงที่ใช้ AI เฉพาะกลุ่มผู้สูงอายุ | **สหรัฐฯ: $352 ล้านในปี 2025 · เหยื่อ 60+ กว่า 3,100 ราย** (แจ้ง FBI) |
| เครื่องมือ | โคลนเสียงจากคลิปสั้น · วิดีโอคอลปลอมแบบเรียลไทม์ |
| ⭐ **ข้อค้นพบทางคลินิก** | **ความสามารถทางการเงินเสื่อมลง*ก่อน*ที่เจ้าตัวจะรู้ตัว** · ภาวะสมองเสื่อมระยะเริ่มต้นเป็นปัจจัยเสี่ยงต่อการถูกหลอก |
| ไทย | เข้าสู่สังคมสูงวัยเร็ว · กำลังแรงงานหดตัว |

> **นัยสำคัญที่สุด**: ถ้าความสามารถเสื่อม*ก่อน*ที่เจ้าตัวจะรู้ตัว แปลว่า **ผู้สูงอายุป้องกันตัวเองไม่ได้โดยนิยาม — ต้องมีคนอื่นสังเกตเห็น** และการสังเกตนั้นต้องอาศัยความสัมพันธ์ที่ทอดยาวข้ามเวลา ซึ่งซอฟต์แวร์ทำแทนไม่ได้

⚠️ **ตัวเลขทั้งหมดข้างบนเป็นของสหรัฐฯ** ต้องหาสถิติไทยมาแทนก่อนใช้จริง (งานสัปดาห์ที่ 1)

---

## 3. ทำไม wedge นี้แรงกว่าตัวเลือกอื่น

| เกณฑ์ | ทำไมผ่าน |
|---|---|
| **เจ็บจริง เร่งด่วน** | ตัวเลข §2 · และทุกคนมีพ่อแม่ |
| ⭐ **ผู้ซื้อคือ*ลูก* ไม่ใช่พ่อแม่** | แก้ปัญหา "ผู้สูงอายุไม่ซื้อบริการการเงิน" ได้หมด — **และลูกคือ ICP ปัจจุบันพอดี** (พนักงานประจำ 1-30 ลบ.) |
| **ไม่ใช่คำแนะนำการลงทุน** | เป็นการป้องกันและให้ความรู้ → พื้นที่กำกับดูแลน้อยกว่ามาก (ยืนยันใน `13` หมวด F) |
| ⭐ **เหตุผลที่ชอบธรรมในการคุยกับคนรุ่นพ่อแม่** | คนที่ถือความมั่งคั่งจริง — **เข้าถึง HNW โดยไม่ต้องขาย** ตรงกับกลไกสะพานใน `14 §5` |
| ⭐ **สร้างความสัมพันธ์สามฝ่าย** | ที่ปรึกษา + ลูก + พ่อแม่ = ตำแหน่ง "จัดการความขัดแย้งในครอบครัว" ซึ่ง `17 §2` ชี้ว่าเป็นงานที่ AI แทนได้ยากที่สุด |
| **คอนเทนต์ที่ทรงพลัง** | เร่งด่วนทางอารมณ์ ส่งต่อได้เอง — เหมาะกับ Writer_Wealth ที่ยังไม่เปิดตัว |
| **ทบต้นเป็นสินทรัพย์** | โปรโตคอล เช็กลิสต์ นิสัยการตรวจสอบ → ใช้ซ้ำได้ |

---

## 4. กลไก 5 ชั้น

เรียงตามอัตราส่วนผลลัพธ์ต่อความพยายาม

| # | ชั้น | ทำอะไร | ต้นทุน |
|---|---|---|---|
| **1** | **รหัสลับในครอบครัว** | คำลับที่ตกลงกันไว้ ใช้ยืนยันตัวตนทางโทรศัพท์ · **ป้องกันการโคลนเสียงได้เกือบสมบูรณ์** | ศูนย์ · ทำได้ในบทสนทนาเดียว |
| **2** | **กติกาหยุดก่อนโอน** | เงินเกิน X บาท ต้องรอ 1 ชม. + **โทรกลับเบอร์ที่บันทึกไว้เอง ไม่ใช่เบอร์ที่โทรเข้ามา** | ศูนย์ |
| **3** | **ผู้ติดต่อที่ไว้ใจได้** | ลงทะเบียนชื่อลูกไว้กับธนาคาร/บลจ. เพื่อให้ติดต่อได้เมื่อพบธุรกรรมผิดปกติ | ต่ำ — ⚠️ ต้องเช็กว่าสถาบันไทยรองรับแค่ไหน |
| **4** | ⭐ **สัญญาณเตือนความสามารถทางการเงินเสื่อม** | สอนลูกว่าต้องสังเกตอะไร — บิลค้างทั้งที่มีเงิน · ตัดสินใจผิดแบบที่ไม่เคยผิดมาก่อน · ไม่ยอมให้ดูบัญชี · เชื่อคนแปลกหน้าง่ายขึ้น · ซื้อของซ้ำโดยไม่รู้ตัว | ต่ำ · **เป็นแก่นที่คนอื่นไม่มี** |
| **5** | **ตรวจสุขภาพการเงินพ่อแม่ประจำปี** | ทบทวนความคุ้มครอง หนี้ สภาพคล่อง ผู้รับผลประโยชน์ พินัยกรรม | นี่คือจุดที่กลายเป็น advisory จริง |

**ชั้น 1-2 ให้ฟรีเสมอ** — เป็น free wedge (ตรงกับ `99-quick-wins` QW-4)
**ชั้น 4-5 คือส่วนที่มีมูลค่า** และนำไปสู่ความสัมพันธ์

---

## 5. เส้นทางลูกค้า

```
คอนเทนต์ (ชั้น 1-2 ให้ฟรีเต็ม ๆ)
   → ลูกอ่านแล้วนึกถึงพ่อแม่ตัวเอง
   → เซสชันครอบครัว (ลูก + พ่อแม่) — ทำชั้น 1-4 ให้
   → พ่อแม่เห็นว่ามีคนที่ไว้ใจได้ และไม่ได้มาขายอะไร
   → ชั้น 5 ตรวจสุขภาพการเงิน
   → ความสัมพันธ์ advisory กับ *ทั้งสองรุ่น*
```

**จุดสำคัญ**: **ลูกเป็นคนจ่ายและเป็นคนชวน พ่อแม่ไม่ต้องถูกขาย** — นี่คือสิ่งที่ทำให้ wedge นี้ไม่ละเมิดหลัก advice-first และไม่ชน role conflict แบบที่ Flow's Table ชน (`14 §5`)

## 6. 🚧 กับดักที่ต้องหลบ — สำคัญกว่ากลไก

| กับดัก | ทางแก้ |
|---|---|
| ⛔ **ขายด้วยความกลัว** | ละเมิด hard gate ของแบรนด์เอง (trust-first) · กรอบที่ถูกคือ **"ดูแลพ่อแม่"** ไม่ใช่ "พ่อแม่คุณกำลังจะเสื่อม" · **ห้ามใช้ตัวเลขความเสียหายเป็นฮุกหลัก** |
| **รู้สึกก้าวก่ายหรืออัปมงคล** | ให้ลูกเป็นคนเปิดเรื่องกับพ่อแม่เอง · เริ่มจากชั้น 1 (รหัสลับ) ซึ่งสนุกและไม่คุกคาม |
| **เคลมเกินความสามารถ** | ไม่ใช่ผู้เชี่ยวชาญด้านฉ้อโกงหรือเวชศาสตร์ผู้สูงอายุ · **อ้างแหล่งเสมอ และบอกชัดว่าตรงไหนไม่ใช่ความเชี่ยวชาญตัวเอง** |
| **ตัวเลขสหรัฐฯ ไม่ใช่ไทย** | หาสถิติไทย (ตำรวจไซเบอร์ · ธปท. · สายด่วน AOC 1441) มาแทน — ⚠️ **ยังไม่ได้ทำ** |
| **กลายเป็นบริการที่ไม่ scale** | เซสชันครอบครัวต้อง productized: ขอบเขตเดียว ราคาเดียว ≤90 นาที |
| **PDPA** | ข้อมูลของพ่อแม่ ≠ ข้อมูลของลูก — ต้องได้ความยินยอมจากเจ้าตัว (ดู `13` หมวด F) |

## 7. ลำดับงาน 8 สัปดาห์ — คู่ขนานกับ Phase 0 ไม่แทนที่

| สัปดาห์ | งาน | เสร็จเมื่อ |
|---|---|---|
| **1** | **หาสถิติไทย** + เช็กกฎ (`13` หมวด F) | มีตัวเลขไทยอ้างได้ ≥3 ชิ้น |
| **2** | เขียนโปรโตคอลชั้น 1-2 เป็นเอกสารหน้าเดียวที่ครอบครัวใช้เองได้ | **ทดสอบกับครอบครัวตัวเองก่อน** — พ่อแม่ตัวเองใช้ได้จริง |
| **3** | ทดสอบกับ **3 ครอบครัวจริง** ฟรี | จับเวลา · จดว่าติดตรงไหน · **จดคำที่เขาพูดเองแบบคำต่อคำ** |
| **4-5** | คอนเทนต์ชุดแรก 3 ชิ้น — ชั้น 1-2 ให้ฟรีเต็ม ๆ | ปล่อยจริง วัดว่ามีคนทักมาไหม |
| **6-8** | ออกแบบเซสชันครอบครัวเป็นสินค้า | มี **≥2 ครอบครัวจ่ายเงินจริง** |

### เกณฑ์ฆ่า

| # | เงื่อนไข | แปลว่า |
|---|---|---|
| 1 | ทดสอบ 3 ครอบครัวแล้ว **ไม่มีครอบครัวไหนทำตามโปรโตคอลต่อหลังจบเซสชัน** | ปัญหาไม่เจ็บพอจะเปลี่ยนพฤติกรรม → **ทิ้ง wedge** |
| 2 | ปล่อยคอนเทนต์ 3 ชิ้นแล้วไม่มีใครทักมาเรื่องพ่อแม่ตัวเอง | ไม่ resonate → กลับไปทบทวนกรอบการสื่อสาร |

## 8. ความเสี่ยงระยะยาวที่ต้องเฝ้า

`17 §6` ข้อ 3: **ถ้าผู้สูงอายุรับ AI companion เป็นคู่คิดที่ไว้ใจที่สุด สิ่งที่ควรปกป้องเขากลายเป็นสิ่งที่แทนที่เรา**

คนเหงาคือคนที่รับ AI companion ง่ายที่สุด และผู้สูงอายุที่โดดเดี่ยวคือกลุ่มเป้าหมายของ wedge นี้พอดี — **เป็นทั้งโอกาสและคู่แข่งในคนเดียวกัน**
