☐ **ไม่มีส่วนที่ซื้อพ่วงเลย** — แปลว่าประกันนี้ไม่ได้ช่วยเรื่องค่ารักษาพยาบาล

**ประกันสุขภาพของคุณเป็นแบบ**: ☐ ซื้อก่อน 8 พ.ย. 2564 (แบบเดิม) ☐ ซื้อตั้งแต่ 8 พ.ย. 2564 (แบบมาตรฐานใหม่) ☐ ไม่มีประกันสุขภาพ

*หมายเหตุ: ตั้งแต่ 8 พ.ย. 2564 ทางการกำหนดให้ประกันสุขภาพทุกบริษัทมีโครงสร้างเหมือนกัน เพื่อให้เทียบกันได้* `[รอข้อมูลจริง — อธิบายความต่างที่กระทบชีวิตจริง]`

# หน้า 3 — ถ้าหยุดจ่ายวันนี้ จะเกิดอะไรขึ้น

**คุณจ่ายไปแล้วทั้งหมดประมาณ ______________ บาท** (ปีละ ______ บาท × ______ ปี)

คุณมี **3 ทางเลือก** ถ้าไม่อยากจ่ายต่อ:

### ทางเลือกที่ 1 — เลิกแล้วเอาเงินคืน

| | |
|---|---|
| **จะได้เงินคืน** | **______________ บาท** |
| หลังจากนั้น | **ประกันจบ ไม่คุ้มครองอะไรอีกเลย** |

### ทางเลือกที่ 2 — หยุดจ่าย แต่ประกันชีวิตยังอยู่ถึงครบสัญญา

| | |
|---|---|
| เงินที่คนข้างหลังจะได้ | ลดจาก ______________ บาท **เหลือ ______________ บาท** |
| คุ้มครองถึง | พ.ศ. ______ (เหมือนเดิม) |

### ทางเลือกที่ 3 — หยุดจ่าย เงินเท่าเดิม แต่คุ้มครองสั้นลง

| | |
|---|---|
| เงินที่คนข้างหลังจะได้ | ______________ บาท (เท่าเดิม) |
| แต่คุ้มครองแค่ถึง | **พ.ศ. ______** แล้วจบ |

> ## ⚠️ สิ่งที่ต้องรู้ก่อนเลือกทางที่ 2 หรือ 3
>
> ### ส่วนที่ซื้อพ่วงไว้ — ค่ารักษาพยาบาลและโรคร้ายแรง — จะหายไปทันที
>
> และถ้าสุขภาพคุณเปลี่ยนไปจากตอนที่ซื้อ **คุณอาจซื้อกลับไม่ได้อีกเลย**
>
> ไม่ใช่เรื่องที่ต้องตัดสินใจวันนี้ — แต่เป็นเรื่องที่ต้องรู้ก่อนตัดสินใจ

☐ **อ่านตารางมูลค่าจากเล่มไม่ได้** — ตัวเลขทั้งหน้านี้ต้องขอจากบริษัท

# หน้า 4 — อะไรที่ไม่คุ้มครอง และคำถามที่ควรถามบริษัท

## สิ่งที่ประกันนี้ไม่จ่าย

1. _______________________________________________
2. _______________________________________________
3. _______________________________________________

☐ **ยังอ่านข้อยกเว้นจากเล่มไม่ครบ** — ขอเอกสารเงื่อนไขฉบับเต็มจากบริษัทได้

## คำถามที่คุณถือหน้านี้ไปถามบริษัทได้เลย

> โทรหาบริษัทที่เบอร์ในเล่มกรมธรรม์ แล้วถามว่า:

1. ☐ "ประกันสุขภาพของดิฉัน/ผม เป็นแบบก่อนหรือหลัง 8 พฤศจิกายน 2564"
2. ☐ "ส่วนที่ซื้อพ่วงไว้ ต้องต่ออายุทุกปีไหม และบริษัทมีสิทธิ์ไม่ต่อไหม"
3. ☐ "ถ้าดิฉัน/ผมหยุดจ่ายเบี้ย ส่วนค่ารักษาพยาบาลจะหายไปจริงไหม"
4. ☐ "ผู้รับผลประโยชน์ที่ระบุไว้ ตอนนี้เป็นใคร" *(ถามเพื่อยืนยันว่ายังตรงกับที่ต้องการ)*
5. ☐ "มีข้อยกเว้นอะไรที่ดิฉัน/ผมควรรู้บ้าง ขอเป็นเอกสาร"
6. ☐ _______________________________________________

## ถ้าไม่ได้คำตอบที่พอใจ

**สายด่วนประกันภัย คปภ. โทร 1186** — หน่วยงานของรัฐที่กำกับดูแลบริษัทประกัน

---

## ขอบเขตของเอกสารนี้

> เอกสารนี้คือ**การอ่านกรมธรรม์ที่คุณมีอยู่แล้ว ให้อยู่ในรูปที่อ่านเข้าใจง่าย** — ไม่ใช่คำแนะนำให้ซื้อ ขาย ยกเลิก หรือเปลี่ยนกรมธรรม์ใด ๆ
>
> ตัวเลขทุกตัวอ่านมาจากเล่มกรมธรรม์ของคุณเอง · **ถ้อยคำที่มีผลผูกพันคือถ้อยคำในกรมธรรม์ของบริษัท ไม่ใช่เอกสารนี้**
>
> หากพบว่าตัวเลขใดไม่ตรงกับเล่มของคุณ โปรดยึดตามเล่ม และแจ้งผู้จัดทำ
