# อภิธานศัพท์ประกัน → ภาษาที่คนอายุ 70 อ่านเข้าใจ

> 🚧 **ร่าง v0.1 · 2026-10-11** — โมดูล `plainlang` (ดู [`19`](../19-product-architecture.md) · PL-1 ใน [`20`](../20-feature-inventory.md))
> ⚠️ **คำแปลในไฟล์นี้ยังไม่ผ่านการตรวจกับถ้อยคำกรมธรรม์จริง** — `[รอข้อมูลจริง]` · **ห้ามใช้ในเอกสารที่ส่งลูกค้าจนกว่าจะตรวจกับเล่มจริง ≥10 เล่ม**
> **เกณฑ์ว่าคำแปลใช้ได้: อ่านออกเสียงให้คนที่ไม่รู้เรื่องประกันฟัง ถ้าต้องอธิบายเพิ่ม แปลว่ายังไม่พอ**

## วิธีใช้ไฟล์นี้

| คอลัมน์ | หมายถึง |
|---|---|
| **ศัพท์** | คำที่อยู่ในกรมธรรม์ |
| ❌ **ห้ามเขียนแบบนี้** | ภาษาที่กรมธรรม์หรือตัวแทนมักใช้ — **ห้ามหลุดเข้าเอกสารลูกค้า** |
| ✅ **เขียนแบบนี้** | ภาษาที่ใช้แทน |
| ⚠️ | เรื่องที่ต้องระวังหรือยังต้องตรวจ |

**กฎเหล็ก**: ถ้าจำเป็นต้องใช้ศัพท์เดิม (เช่นเพราะมันอยู่บนเอกสารที่ลูกค้าถือ) ให้เขียนศัพท์แล้ววงเล็บคำแปลต่อท้ายทันที **ห้ามใช้ศัพท์เดี่ยว ๆ**

| ร่วมจ่าย (co-payment) | "ร่วมจ่าย 20%" | **"ค่ารักษาทุก 100 บาท คุณจ่าย 20 บาท บริษัทจ่าย 80 บาท"** | |

## 3. ⭐ ถ้าหยุดจ่าย — ส่วนที่สำคัญที่สุดและคนเข้าใจน้อยที่สุด

| ศัพท์ | ❌ ห้ามเขียนแบบนี้ | ✅ เขียนแบบนี้ | ⚠️ |
|---|---|---|---|
| ระยะเวลาผ่อนผัน (grace period) | "grace period 31 วัน" | **"จ่ายช้าได้ 31 วัน ยังไม่ขาด"** | ⚠️ `[รอตรวจ]` จำนวนวันต่างกันตามแบบ |
| กรมธรรม์ขาดอายุ (lapse) | "กรมธรรม์ขาดอายุ" | **"ประกันหมดสภาพ ไม่คุ้มครองอีก เพราะไม่ได้จ่ายเบี้ย"** | |
| ⭐ มูลค่าเวนคืนกรมธรรม์ | "มูลค่าเวนคืน 142,000 บาท" | **"ถ้าคุณเลิกวันนี้ จะได้เงินคืน 142,000 บาท แล้วประกันจบ ไม่คุ้มครองอีก"** | |
| ⭐⭐ มูลค่าใช้เงินสำเร็จ (paid-up) | "แปลงเป็นกรมธรรม์ใช้เงินสำเร็จ" | **"หยุดจ่ายได้เลย ประกันชีวิตยังอยู่ถึงครบสัญญา แต่เงินที่จะได้ลดจาก 1,000,000 เหลือ ____ บาท"** <br>+ **"⚠️ และค่ารักษาพยาบาลของคุณจะหายทันที"** | **ต้องเขียนคำเตือนด้วยทุกครั้ง ไม่มีข้อยกเว้น** |
| ⭐ มูลค่าขยายเวลา (extended term) | "แปลงเป็นการขยายเวลา" | **"หยุดจ่ายได้ เงินที่จะได้เท่าเดิม 1,000,000 บาท แต่คุ้มครองแค่ถึงปี พ.ศ. ____ แล้วจบ"** | + คำเตือนเรื่องสัญญาเพิ่มเติมเช่นกัน |
| การกู้เงินตามกรมธรรม์ | "กู้ตามกรมธรรม์" | **"ยืมเงินจากกรมธรรม์ตัวเองได้ แต่ต้องเสียดอกเบี้ย และถ้าไม่คืน เงินที่คนข้างหลังได้จะลดลง"** | ⚠️ `[รอตรวจ]` อัตราดอกเบี้ยต่างกันตามแบบ |
| ผลประโยชน์ครบกำหนดสัญญา | "เงินครบสัญญา" | **"ถ้าคุณอยู่ถึงปี พ.ศ. ____ จะได้รับ ____ บาท"** | |

> ### ⛔ กฎที่ห้ามละเมิดในหมวดนี้
> **ทุกครั้งที่พูดถึงการหยุดจ่ายหรือแปลงกรมธรรม์ ต้องเขียนด้วยว่าสัญญาเพิ่มเติม (ค่ารักษาพยาบาล · โรคร้ายแรง) จะหายไป และซื้อกลับไม่ได้ถ้าสุขภาพเปลี่ยนไปแล้ว**
>
> นี่คือข้อเท็จจริงที่มีประโยชน์ที่สุดต่อลูกค้า **และเป็นข้อเท็จจริงเดียวกับที่ปกป้องเขาจากการถูกชวนยกเลิกกรมธรรม์เดิม** — ดู `19 §5`

## 5. คำที่ห้ามใช้เลยในเอกสารลูกค้า

| ❌ ห้ามใช้ | เพราะ |
|---|---|
| "ควร" · "แนะนำให้" · "เหมาะกับคุณ" | ⛔ กลายเป็นคำแนะนำ — ชน `guard` GU-1/GU-2 และอาจชน `13` G1 |
| "ของเดิมไม่ดี" · "ล้าสมัย" · "เสียเปรียบ" | ⛔ ชน GU-2 โดยตรง — เครื่องมือนี้ไม่ตัดสินกรมธรรม์ของใคร |
| "คุ้มกว่า" · "ดีกว่า" เมื่อเทียบกับสินค้าที่กำลังขาย | ⛔ ชน GU-1 |
| "โอกาสสุดท้าย" · "รีบตัดสินใจ" | ⛔ ละเมิด hard gate ของแบรนด์ (`16 §6`) |
| ศัพท์อังกฤษที่ไม่แปล (deductible · co-pay · paid-up · lapse) | ผู้อ่านอายุ 70 |
| ตัวย่อชื่อสัญญาเพิ่มเติม (HS · DCI · AI · ADB) | ไม่มีใครรู้ว่าคืออะไร รวมถึงลูกค้าที่ถือมัน 20 ปี |

## 6. สิ่งที่ยังต้องทำกับไฟล์นี้

- [ ] ตรวจทุกคำแปลกับถ้อยคำกรมธรรม์จริง ≥10 เล่ม ≥4 บริษัท
- [ ] ทดสอบอ่านออกเสียงกับคนที่ไม่รู้เรื่องประกัน 3 คน
- [ ] เพิ่มหมวดสำหรับ **R-FAMILY** (ศัพท์เรื่องการฉ้อโกงและการมอบอำนาจ)
- [ ] กำหนด **เกณฑ์วัดความอ่านง่ายภาษาไทย** (PL-2) — ⚠️ ไทยไม่มีมาตรวัดแบบ Flesch **ต้องตั้งเกณฑ์เอง ห้ามเดาว่ามีเครื่องมือสำเร็จรูป**
