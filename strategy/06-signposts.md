## ตัวชี้วัดหลัก

| ID | วัดอะไร | วัดยังไง | **ถ้าขยับแบบนี้ = อะไร** |
|---|---|---|---|
| **SP-1** | ต้นทุนต่อ task ของงานอ้างอิงที่เรากำหนดเอง | รัน task ชุดเดิม (10 งาน) ทุกเดือน จดต้นทุนจริง | ลง >50%/ไตรมาส = adoption จะเร่ง เตรียมของให้ทัน |
| **SP-2** ⭐ | โมเดลตรวจงานตัวเองแม่นแค่ไหน | รัน self-check บนชุดงานที่เรารู้เฉลย จดอัตราจับผิดได้ | **>90% = สมมติฐานแกนพัง F1/F2 ตายทั้งคู่** |
| **SP-3** | ราคาของ "การตรวจโดยคน" | ดูราคา expert review marketplace | ลงแรง = คนถูกกว่าเครื่อง ตลาด verification หด |
| **SP-4** | มีใครขาย outcome-based เพิ่มไหม | นับรายที่ประกาศราคาต่อผลลัพธ์ ทุกเดือน (ฐาน ส.ค. 2026: Zendesk $1.50, Intercom $0.99) | **โตต่อเนื่อง = F1 ถูกทาง · หยุดนิ่ง 2 ไตรมาส = ตลาด F1 เล็กเกินไป** |
| **SP-5** ⭐ | vendor ดูด feature ชั้น infra เร็วแค่ไหน | ตามอ่าน changelog ของ Anthropic/OpenAI/Google รายเดือน จดว่ากินสนามไหนไปแล้ว | ถ้ากิน eval+identity+billing ครบ = กลุ่ม B/C ตายเกือบหมด |
| **SP-6** | เงินทุนไหลเข้าสนาม agent | ตามตัวเลข funding รายเดือน (ฐาน: ก.ค. 2026 ~$1.8B/12+ ดีล) | ลง >60% 2 ไตรมาสติด = ลูกค้า builder จะหาย → เร่งย้ายไป F3 |
| **SP-7** | ลูกค้าเราคือคนที่มี P&L จริงหรือคนที่มีเงิน VC | นับสัดส่วนในลิสต์ลูกค้าจริง | VC-funded >70% = เปราะเกินไป กระจายด่วน |
| **SP-8** | มาตรฐาน S3 ลงตัวหรือยัง | ตาม AP2 / ACP / UCP / x402 — ดูว่ามีตัวไหนถูกใช้จริงในปริมาณ ไม่ใช่แค่ประกาศ | ตัวใดตัวหนึ่งชนะชัด = **ดึง D4 (SEO for agents) และ C2 (agent identity) กลับมาทันที** |
| **SP-9** | agent identity ถูกแก้หรือยัง | ดูว่า AP2 หรือใครผูก mandate กับ *agent* ได้แล้วหรือยัง (ณ ส.ค. 2026 ยัง — ผูกกับ key ของ *คน*) | แก้ได้เมื่อไร = S3 ใกล้เข้ามาจริง |
| **SP-10** | ท่าทีของ regulator เรื่องความรับผิดของ AI | ตามข่าว EU AI Act + regulator ภาคการเงิน/สุขภาพ | เข้มขึ้น = **ข่าวดีสำหรับ F1/C7** (ยิ่งต้องมีคนกลางตรวจ) |
| **SP-11** | งานที่หายจริง vs ที่พูดกันว่าจะหาย | ดูข้อมูลตลาดแรงงานจริง เทียบกับพาดหัวข่าว | ช่องว่างกว้าง = อยู่ในช่วง hype ให้ถ่วงน้ำหนักคำพูดลูกค้าลง |

## Tripwire — เมื่อไรต้องหยุดทั้งแผน

🔴 **หยุดและกลับไปเขียน `01-world-model.md` ใหม่** เมื่อเกิด **≥2 ข้อ** ในไตรมาสเดียว:
- SP-2 > 90% (โมเดลตรวจตัวเองได้)
- SP-4 หยุดนิ่ง 2 ไตรมาสติด (outcome pricing ไม่ขยาย)
- SP-5 vendor กิน ≥2 สนามที่เราเล็งไว้
- SP-6 ลง >60% สองไตรมาสติด

**สิ่งที่ห้ามทำเมื่อ tripwire ลั่น**: ปรับหน้างานไปเรื่อย ๆ แล้วบอกตัวเองว่า "กำลัง pivot" — การ pivot ที่ไม่ได้แก้ world model คือการเดินวนด้วยความเร็วสูง

🟢 **เร่งลงทุนหนักขึ้น** เมื่อเกิด ≥2 ข้อ:
- SP-4 โตต่อเนื่อง 2 ไตรมาส
- SP-10 regulator เข้มขึ้นจริง
- ลูกค้าเริ่มถามหาเราเองก่อนที่เราจะไปหา
