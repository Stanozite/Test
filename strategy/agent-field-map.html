แผนที่สนามยุค Agent Economy

เมื่อการผลิตงานถูกลงจนเกือบฟรี คอขวดจะย้ายจาก “ทำได้ไหม” ไปเป็น “รู้ได้ไงว่าถูก” และ “ใครยอมให้ทำ” — มูลค่าย้ายตามคอขวดเสมอ นี่คือแผนที่ว่าคอขวดกำลังอยู่ตรงไหน เงินเริ่มเปลี่ยนมือตรงไหน และเราจะยืนตรงไหนได้

Picks & Shovels Global-first ทุน + เวลาเต็มตัว + สร้างเองได้ สถานะ: Phase 1 เสร็จ · ยังไม่ตัดสินใจ

อย่าแข่งทำ agent ที่เก่งกว่า — ขายของที่ทุกคนที่จะ deploy agent ต้องซื้อ ไม่ว่า agent ตัวไหนจะชนะ

ข้อดีเชิงโครงสร้างของบทบาทนี้: เราไม่ต้องรอให้ตลาด agent สำเร็จ เราได้เงินจากคนที่กำลังพยายาม ไม่ว่าเขาจะสำเร็จหรือไม่ ข้อเสียที่ต้องเขียนไว้ให้เจ็บ: ถ้าคลื่นนี้เป็นฟองสบู่ ลูกค้าเราคือกลุ่มแรกที่ตาย — จึงต้องเลือกสนามที่ลูกค้ามี P&L จริง ไม่ใช่มีแต่เงิน VC

02

ฉากทัศน์ S0 → S4

ไม่ใส่ปี ใส่สัญญาณที่ตรวจสอบได้แทน — การทำนายปีคือวิธีหลอกตัวเองที่นิยมที่สุด และโลกไม่ได้เดินพร้อมกันทุกอุตสาหกรรม customer support อยู่ S2 แล้ว ขณะที่ legal และ healthcare ยังอยู่ S0–S1

S0

Copilot

agent นั่งข้างคน คนกดทุกปุ่ม ผลิตภาพขึ้นในงานที่วัดยาก

ขายเป็น seat/เดือน — จริงและใหญ่แล้ว แต่บาง churn สูง

ต้องมีก่อน: แค่ browser

S1

Delegated task

agent ทำงานเป็นชิ้นจบเอง คนกลายเป็นคนรีวิว — โลกส่วนใหญ่ยืนตรงนี้

seat + usage · บริการ deploy/integrate ขายได้แพง เพราะ demand > supply

ต้องมีก่อน: ต่อระบบจริงได้ · audit log · คนที่ยอมรีวิว

S2

Agent as worker

agent เป็นเจ้าของ workflow ทั้งเส้น มี SLA คนดูเฉพาะ exception

Outcome pricing — Zendesk $1.50/resolution, Intercom Fin $0.99 · ล้มเหลว = ไม่คิดเงิน ผู้ขายแบกความเสี่ยง 100%

ต้องมีก่อน: identity ของ agent · spend control · eval ที่เป็นสัญญา · exception desk

S3

Agent-to-agent

agent ซื้อขายจ้างกันเอง การตลาดเปลี่ยนจาก “ทำให้คนคลิก” เป็น “ทำให้ agent เลือก”

ค่าธรรมเนียมต่อธุรกรรม · ค่า discovery · ค่าตัดสินข้อพิพาท

ต้องมีก่อน: ชื่อเสียง/attestation · การระงับข้อพิพาท · และ agent identity ที่ยังไม่มีใครแก้ได้

S4

Full adoption

บริษัท 3 คน output เท่า 300 คน · คนเหลืองาน 4 อย่าง: ทิศทาง รสนิยม ความรับผิด ความสัมพันธ์

มูลค่าไหลไป compute · ข้อมูลเฉพาะ · สินทรัพย์จริง · แบรนด์

ตัวถ่วงจริง: ไม่ใช่เทคโนโลยี แต่คือกฎหมายและความไว้ใจ — ช้ากว่าโมเดล 5–10 เท่า

↑ MARGIN POOL  จุดที่ลูกค้ายอมจ่ายตามผลลัพธ์แทนที่นั่งเป็นครั้งแรก — แต่สำหรับ picks & shovels เงินมาเร็วกว่านี้ เพราะเราขายให้คนที่กำลังพยายามไปถึง S2 เขาจ่ายก่อนที่ของเขาจะ work

3 ตัวที่เสนอเข้ารอบพิสูจน์

นี่คือข้อเสนอ ไม่ใช่การตัดสินใจ — การตัดสินใจเกิดที่ Gate 2 ด้วยหลักฐานว่ามีคนจ่ายจริง F1 กับ F2 correlate กันสูง (ลูกค้ากลุ่มเดียวกัน ตายพร้อมกันถ้าสมมติฐานแกนผิด) F3 จึงเป็นประกัน ห้ามตัดทิ้งเพราะ “ไม่เท่”

F1 · D2+D3+B269

Outcome Verification

เป็นคนกลางที่พิสูจน์ว่า “งานที่ agent ทำ นับเป็นผลสำเร็จจริงไหม” ให้บริษัทที่ขายแบบจ่ายต่อผลลัพธ์

ทำไมน่าจะจริง

outcome pricing เกิดแล้ว ไม่ใช่ทฤษฎี — และเมื่อผู้ขายแบกความเสี่ยง 100% เขายอมจ่ายแพงมากเพื่อพิสูจน์ว่าสำเร็จจริง Deloitte ออกเอกสารเรื่องการบัญชีของมันแล้ว = ปัญหาไปถึงฝ่ายการเงินแล้ว

Moat = ความเป็นกลาง

vendor ทำเองไม่ได้เพราะ conflict of interest — ไม่มีใครยอมให้ผู้ขายตัดสินเองว่างานตัวเองสำเร็จ เหมือนผู้สอบบัญชี

ต้องฆ่าสมมติฐานนี้ก่อน

ตลาดใหญ่พอไหม — ตอบแล้วว่าใหญ่ ~21.7% ของสัญญาองค์กร · คำถามใหม่: กว้างพอจะเป็นบริษัทไหม ต้องได้ ≥12 รายนอก CX และ ≥8 รายที่ยืนยันราคาจากเว็บตัวเอง ไม่ครบ = ฆ่า

F2 · B3+B765

Self-building Eval

เปลี่ยน traffic จริงใน production ให้กลายเป็นชุดทดสอบเองอัตโนมัติ แล้วเตือนตอน agent เริ่มผิดแบบเนียน ๆ

ทำไมน่าจะจริง

ทุกทีมรู้ว่าต้องมี eval แต่ไม่มีเวลาสร้าง golden set — ปัญหาไม่ใช่ “ไม่มีเครื่องมือ” แต่คือ “ไม่มีข้อมูลจะใส่เครื่องมือ” ตลาดวันนี้ขายเครื่องมือเปล่า

Moat = ทบต้น

ยิ่งลูกค้าใช้ eval set ยิ่งแม่นและย้ายออกยาก

ต้องฆ่าสมมติฐานนี้ก่อน

เป็น vitamin หรือ painkiller — สมัคร 50 คนแต่กลับมาใช้รอบที่ 3 น้อยกว่า 2 คน = ฆ่า

F3 · E1+E2 · hedge65

Domain Ground-Truth Feed

ขายข้อมูลที่ถูกและอัปเดตในโดเมนที่ผิดแล้วเสียเงินจริง ในรูปที่ agent กินได้ทันที

ทำไมอยู่ในลิสต์

ไม่ correlate กับ F1/F2 — ถ้าฟองสบู่ tooling แตก F1/F2 ตายพร้อมกัน แต่ F3 ไม่ตายเพราะลูกค้าคือคนที่มี P&L จริง

Moat = ข้อมูลสะสม + ความรับผิด

vendor ไม่แตะเพราะต้องรับผิดชอบความถูกต้อง งานเก็บข้อมูลหนักและน่าเบื่อ — ซึ่งก็คือ moat นั่นแหละ

ต้องฆ่าสมมติฐานนี้ก่อน

โมเดลรู้อยู่แล้วหรือเปล่า — ถ้าทุกโดเมนที่ทดสอบ LLM เปล่าผิดน้อยกว่า 15% = ไม่มีช่องว่างให้ขาย
