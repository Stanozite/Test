# Agent Economy Playbook — ชุดเอกสารเตรียมตัว capture โอกาส

> สร้างเมื่อ 2026-08-29 · เจ้าของ: Tin · สถานะ: **Phase 0–1 เสร็จ, ยังไม่ตัดสินใจว่าจะ build อะไร**

## นี่คืออะไร

ชุดเครื่องมือคิด–ตัดสินใจ–ลงมือ สำหรับคำถามว่า *"ในโลกที่ agent ทำงานแทนคน โอกาสอยู่ตรงไหน และเราจะเข้าไปเป็นส่วนหนึ่งได้ยังไง"*

ไม่ใช่แผนธุรกิจ — เป็น **ระบบสำหรับหาแผนธุรกิจ** ที่ออกแบบให้ตัดสินใจด้วยหลักฐาน ไม่ใช่ด้วยความตื่นเต้น

## ทุนตั้งต้นที่ระบบนี้ถูกออกแบบมาให้ใช้

| ทุน | ผลต่อการออกแบบ |
|---|---|
| เงินทุน + เวลาเต็มตัว | รับ payback หลายเดือนได้ → เลือกสนามที่ลึกได้ ไม่ต้องรีบหาเงินเดือนหน้า |
| สร้างซอฟต์แวร์/agent ได้เอง | ต้นทุนต่อการทดลอง 1 รอบ ≈ 0 → กลยุทธ์คือ **ทดลองเยอะ ไม่ใช่คิดนาน** |
| บทบาท: picks & shovels | ขายให้คนที่กำลังสร้าง ไม่ใช่แข่งทำ agent เอง |
| ตลาด: global-first ออนไลน์ | ต้องขายได้โดยไม่มีทีมขาย → self-serve หรือ founder-led ผ่าน async |

## กฎ 5 ข้อของระบบนี้

1. **เขียนเกณฑ์ก่อนดูตัวเลือกเสมอ** — กัน motivated reasoning
2. **หลักฐานเดียวที่นับคือเงินหรือ commitment ที่มีต้นทุน** — คำชมไม่นับ, "น่าสนใจมาก" ไม่นับ
3. **ตัวเลขต้องมีแหล่ง** ไม่งั้นติดป้าย `[ต้องหาข้อมูล]` — ห้ามเดาแล้วเขียนเหมือนรู้
4. **ทุกสมมติฐานต้องผิดได้** — ถ้าเขียนแบบผิดไม่ได้ แปลว่ายังไม่ได้คิด
5. **`probe-log.md` เป็น append-only** — ห้ามแก้ผลย้อนหลังให้เข้าข้างตัวเอง
