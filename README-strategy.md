## ทิศทางปัจจุบัน

> **จุดยืน advice-first ที่ประกาศไว้ ไม่เคยเป็นไปได้เชิงต้นทุน — AI เพิ่งทำให้มันเป็นไปได้**

วางแผนการเงินครัวเรือนให้ครบจริงกิน 3-6 ชม./ราย · ที่ความมั่งคั่ง 1-30 ล้านบาท เก็บค่าที่ปรึกษาให้คุ้มเวลานั้นไม่ได้ → ทางเดียวที่ได้เงินคือขายผลิตภัณฑ์ → คำแนะนำเอนเอียงตั้งแต่ต้น
**AI ตัดตัวเลข 3-6 ชม. ลง เศรษฐศาสตร์จึงกลับด้าน**

**ทุนที่แผนนี้ใช้จริง**: ใบอนุญาต · ลูกค้าที่วิ่งอยู่แล้ว · เขียนโค้ดเอง · เขียนคอนเทนต์ไทยเป็น · runway > 18 เดือน
**สิ่งที่ตัดออก**: agent infra ตลาดโลก · Flow's Table เป็นเครื่องยนต์ (ตัดสินใจคนเดียวไม่ได้) · เอเจนต์คอนโดในฐานะธุรกิจ

## เส้นทาง

```
Phase 0  วัดเวลาต่อลูกค้า       สัปดาห์ 1-8    → วิเคราะห์กี่ % · ความสัมพันธ์กี่ %
   ══ ถ้าความสัมพันธ์ ≥70% → practice ขยายไม่ได้ ต้องข้ามไป Phase 2 หรือขึ้นเซกเมนต์ ══
Phase 1  Practice ที่ AI ทำ 80%  เดือน 2-6     → เวลาต่อลูกค้าลด ≥50% · ลูกค้าใหม่ ≥2 เท่า
Phase 2  เครื่องมือให้ที่ปรึกษา  เดือน 6-12    → ตัวแทน 15 คน ยอมจ่าย 500-1,500/เดือนไหม
```

**คู่ขนานตลอด**: คอนเทนต์เปลี่ยนทิศ — ยังไม่เปิดตัว = เปลี่ยนได้ฟรี · เขียนแคบและลึกในฐานะ**หลักฐานของวิจารณญาณ** ไม่ใช่ช่องส่งข้อมูล

## กฎที่ยังใช้อยู่ (จากงานรอบเดิม)

1. **เขียนเกณฑ์ก่อนดูตัวเลือก** — และ **calibrate rubric ก่อนใช้ตัดสินใจ ครั้งที่แล้วข้ามข้อนี้และมันทำให้ผลลัพธ์เป็น noise**
2. **หลักฐานที่นับคือเงินหรือ commitment ที่มีต้นทุน** — สามรอบที่แล้วผลิตเอกสารเยอะ คุยกับลูกค้าศูนย์ราย อย่าทำซ้ำ
3. **ตัวเลขต้องมีแหล่ง** ไม่งั้นติดป้าย `[ต้องหาข้อมูล]`
4. **ทุกสมมติฐานต้องผิดได้** — พร้อมจุดที่ตรวจว่ามันผิด
5. **บันทึกผลดิบแบบ append-only** ห้ามแก้ย้อนหลังให้เข้าข้างตัวเอง
